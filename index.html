ℹ Despre această pagină

Interfață inspirată de stilul vizual KingsAge, realizată ca pagină statică HTML pentru GitHub Pages. Datele inițiale din fișierul TXT sunt incluse în pagină.

Utilizare: poți căuta atacuri, filtra după tip, grupa țintele, descărca CSV și importa un alt raport TXT prin butonul „Încarcă TXT”. Nimic nu este trimis către un server.

Linkuri: apăsarea pe o coordonată deschide harta lumii s55-br în KingsAge (poate necesita autentificare).

Limitare: aceasta nu este o conexiune live la joc; pagina nu recuperează automat atacurile și nu poate confirma tipul real al trupelor din atacurile fake.

Publicare: încarcă fișierul index.html în rădăcina unui repository GitHub și activează Settings → Pages → Deploy from a branch → main / root.
